Especificaciones Técnicas

  • Clasificación Automatizada: Identificación selectiva de botellas PET y latas de aluminio mediante sensores de proximidad y peso.
  • Interfaz de Usuario: Pantalla táctil interactiva con guías dinámicas para el usuario final.
  • Ecosistema IoT: Conectividad en tiempo real para actualización de inventario de tolva, alertas de mantenimiento y control de recompensas.
  • Capacidad Compacta: Optimizado para supermercados, universidades y espacios públicos de alto tráfico.
